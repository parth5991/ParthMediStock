# ParthMediStock

A pharmacy inventory analytics project developed as part of a Data Analytics portfolio.

## Project Overview

ParthMediStock is a data analytics project designed to analyse pharmacy inventory, medicine expiry dates, stock availability, pricing, and inventory valuation. The project aims to identify potential inventory losses, monitor stock levels, and generate meaningful business insights.

The project demonstrates practical Data Analytics skills using Microsoft Excel, SQL, and Power BI.

## Dataset Overview

The dataset contains 50 unique fictional medicines and 150 unique medicine batch records.

The original raw dataset contains 155 records, including 5 intentionally duplicated rows for data-cleaning practice.

Each row represents an individual medicine batch, allowing the analysis of different expiry dates and stock quantities for the same medicine.

The dataset includes the following fields:

1. Medicine ID
2. Medicine Name
3. Manufacturer
4. Medicine Type
5. Intended Use
6. Prescription Required
7. Unit Cost
8. Selling Price
9. Reorder Level
10. Batch Number
11. Expiry Date
12. Quantity in Stock

## Notes

ParthMediStock is a fictional pharmacy inventory analytics project created for portfolio and learning purposes.

The dataset uses fictional medicine names, manufacturers, batch numbers, pricing, and inventory information.

The project focuses on inventory management and does not include customer billing history, patient personal information, medical diagnosis, or sales forecasting.
